# Mobiliscope, local reproduction on Linux with Docker

An independent exercise in running the [Mobiliscope](https://mobiliscope.cnrs.fr) website (v4.3) locally, from its two public repositories and its open data. Not affiliated with the Mobiliscope project.

- Setup, results and limits: [README_setup.md](README_setup.md)
- Draft CodeMeta 4.0 metadata for the two repositories: [CODEMETA_notes.md](CODEMETA_notes.md), [codemeta/](codemeta/)
- R check of the published Duncan indices: [r_check/duncan_check.R](r_check/duncan_check.R)
- An OGC API over one city of the open data, served by GeoServer: [ogcapi/README_api.md](ogcapi/README_api.md)

The Mobiliscope code (AGPL-3.0) and data (ODbL, doi:10.5281/zenodo.11111161) are not redistributed here. Credit: Vallée J, Douet A, Le Roux G, Commenges H, Lecomte C, Villard E (2024). Mobiliscope [v4.3]. www.mobiliscope.cnrs.fr.
